on-demand variant User parameter overrides → Lambda / Modal render → signed URL.

From the recap page, a variant form lets a creator override sponsor tier visibility, music track, locale (en / zh / id), or scene order. Worker posts to POST /api/recap-reel/render with the override payload, returns a render-job id, polls until ready, opens the signed R2 URL. Typical latency 30–90s on Lambda / Modal.

How this slots into the existing event-recap stack

  1. Component library (top of mock) lives at components/recap/{XPostCard,LinkedInPostCard,YouTubeCard,SponsorLogo,LowerThird,Watermark,SoundCue}.tsx. Each takes a typed slice of EventPost / EventConfig. Same components are imported by the worker HTML renderer AND the Remotion composition — one source of truth for visual identity across web + MP4.
  2. Mocks A + B render in workers/aie2026-vibes.ts (and the generic event-recap-vibes.ts template) — adding renderHeroReel() + renderSponsorBand() next to the existing renderShell(). Hero reel tiles pick the top-reach posts; the X/LinkedIn/YouTube card variant is selected from post.platform.
  3. Mock C is a Remotion composition at src/remotion/EventRecap/{index.tsx,Title.tsx,StatScene.tsx,RankingScene.tsx,MomentScene.tsx,MontageScene.tsx,CascadeScene.tsx,SponsorScene.tsx,VoiceScene.tsx,Outro.tsx}. Each scene composes the library components above. Transitions (whip-pan, slide-up, scale-fade, wipe) live in src/remotion/transitions/. Audio bed: a 60s royalty-free track plus per-scene SFX (boom · swell · ticks · synth pluck · swish · chord · final boom) keyed off scene timestamps — annotated inline on the mock so the editor knows exactly what plays where.
  4. renderRecapReel(bundle, config, variant) uses @remotion/renderer on Lambda/Modal, writes recap-9x16.mp4 (TT/Reels/Shorts) and recap-16x9.mp4 (YouTube/LinkedIn/X video) to R2 at event-recap-{eventId}/. Cron hook in slice 11 calls it post-refresh; on-demand variants flip props (sponsor-tier visibility · music track · locale · scene order).
  5. Mock D is a new Next.js route at app/vibes/aie/page.tsx. Reads each AIE EventConfig, fetches public bundles in parallel, renders the grid + cross-event consolidation. Cross-event computation lives in lib/research/event-recap/aggregate.ts — pure function over EventRecapBundle[].
  6. Reusability: adding a new event (e.g. AIE Tokyo 2026) is a config commit + one worker route + one cron entry. The recap reel + sponsor band + voice carousel + MP4 composition all re-render against the new bundle automatically.
  7. Provenance (CLAUDE.md hard rule #8): each rendered MP4 records a versioned ToolRef with { inputs: bundle.id, outputs: r2Path, beforeSnapshotRef, afterSnapshotRef, variant } so reruns are auditable.
